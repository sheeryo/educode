# EduCode — Платформа онлайн-курсов языков программирования

## 1. Тема сайта и целевое действие пользователя
EduCode — образовательная платформа онлайн-курсов, предлагающая интерактивные курсы по популярным языкам программирования (Python, JavaScript, C++, и т.д.).
Целевое действие пользователя на сайте - ознакомиться с направлениями, выбрать подходящий курс и оставить заявку на обучение.

## 2. Карта маршрутов
- `/` - Главная страница
- `/about` - О проекте
- `/services` - Услуги и тарифы
- `/contacts` - Контакты

## 3. Выделенные компоненты
- `Header` - шапка веб-сайта (логотип сайта и навигационное меню)
- `Footer` - нижний блок веб-сайта (авторские права и навигация)
- `Hero` - главный блок веб-сайта, который пользователь сразу видит после открытии.
Перечисленные компоненты в папке `components/` были использованы для предотвращения дублирования кода.

## 4. Реализование закрепления шапки
Шапка реализована с использованием `sticky` позиционирования. Почему я его использовал: пользователь имеет постоянный доступ к шапке, удобна для мобильных устройств, сохраняет свое исходное место в структуре страницы и не перекрывает соседние блоки в отличие от `fixed`.

## 5. Адаптивность Hero
Адаптивность блока Hero реализована через flexbox с помощью tailwind `(md:)`.
У мобильных устройств контент выстраивается вертикально `flex-col`.
В десктопе блок трансформируется в `flex-row`, текст и кнопка слева, а картинка справа.

## 6. Что сознательно не усложнялось
- Сторонние UI-библиотеки не подключались, стили только через tailwind css.
- Без интеграции с бэкендом.
